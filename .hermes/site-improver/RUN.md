# HBOTQ Site Improvement Tracker
# Nightly automation — each run picks next pending item, executes, updates log

## Site Info
- URL: https://hbotq.com
- Repo: github.com/Marketing-Bull/hbotq
- Branch: `improve-credibility-conversion` (create or use existing)
- Stack: Next.js 14 + Tailwind CSS + TypeScript

## How It Works
- RUN.md (this file) is the master control document
- TODO.md tracks pending/in-progress/completed items
- COMPLETED.md logs all finished work with dates + PR links
- Site audit runs on a regular cadence; output feeds into new TODO entries

## Audit Categories
- SEO / AI Search (schema, meta, structured data, indexability)
- Web Design / UX (layout, CTAs, mobile, Core Web Vitals feel)
- Schema / Structured Data (JSON-LD for LocalBusiness, FAQ, etc.)
- Tracking / Analytics (GTM, events, pixels, form tracking)
- Conversion (form UX, trust signals, social proof, CTA copy)
